Example scenario: 
******************
UI Component: project-assign-dialog.component.html
HTML code: 

        <ux-button            
			*pmwpApplySecurity="{name: 'projectsList.assignTo', context: {projectId: _project()?.id}}"            
			class="assign-to-me"            
			size="extraSmall"            
			type="light"            
			[uxTooltip]="'Assign this Project to user/team.' | translate"            
			[uxTooltipArrow]="true"            
			[icon]="editAssignIcon"            
			[disabled]="disableButtonForTerminalState()"            
			(onClick)="openAssignPopover()">
		</ux-button>

Step-by-Step Execution:
***********************

Step 1: Directive Activation
=============================
- When Angular renders this component, the *pmwpApplySecurity directive is triggered
- Input provided: {name: 'projectsList.assignTo', context: {projectId: _project()?.id}}
- name: 'projectsList.assignTo' (the UI_element_Id)
- context: The specific project being displayed

Step 2: Lookup Security Mapping
================================
- The GrantsService looks up 'projectsList.assignTo' in UI_ELEMENT_MAPPING
- It finds this mapping:
- security-mapping.ts: 
    [
		'projectsList.assignTo', {        
			type: ABAC_RESOURCES.ProjectManagerParty,        
			operation: ABAC_OPERATIONS.CREATE,    
		}
	],    
- Translation: "Can this user CREATE a ProjectManagerParty (assign a manager) for this project?"

Step 3: Build the Security Request
===================================
- Combines the ABAC rule with the context:
- Resource Type: ProjectManagerParty
- Operation: CREATE
- Context: {projectId: _project()?.id} (e.g., {projectId: "12345"})

Step 4: Check Cache
====================
- SecurityCacheService checks if this exact permission was already evaluated
- Cache Hit: Return the cached result immediately (fast!)
- Cache Miss: Continue to Step 5

Step 5: Call Backend (if needed)
================================
- AccessControlService sends HTTP POST to: /preview/v1/check/resource/bulk/operations
- Payload asks: "Can current user CREATE ProjectManagerParty for project 12345?"
- Backend evaluates using ABAC policies (user roles, project context, business rules, etc.)

Step 6: Cache the Result
=========================
- Response is stored in SecurityCacheService
- Future checks for the same permission will be instant

Step 7: Apply Result to UI
===========================
- If Permission = TRUE (Allowed): 
	1. Button is rendered in the DOM
	2. Button gets pmControlId="projectsList.assignTo" attribute added
	3. User sees: "Assign to user/team" button
	4. User can click to open the assignment popover
- If Permission = FALSE (Denied):
	1. Button is completely removed from the DOM
	2. User sees nothing (button doesn't exist in HTML) It's as if the button was never there
