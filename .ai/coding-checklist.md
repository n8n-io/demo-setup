# AI Coding Checklist

Before proposing a pull request, confirm:

## Logic
- Feature or fix works as expected
- Edge cases handled

## Tests
- Unit tests added
- Integration tests added (if applicable)
- Regression test added (for bug fixes)

## Quality
- Linting passes
- Formatting passes
- Type checks pass (if applicable)

## Security
- No secrets in code
- No insecure defaults
- Dependencies are approved

## Architecture
- Follows repo structure
- No new frameworks introduced
- Naming conventions followed

## PR Size
- Change is small and focused
- Ideally under 600 lines

If any item fails:
→ Fix before submitting PR.
