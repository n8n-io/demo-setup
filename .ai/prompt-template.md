# Rapidify Standard Prompt Template

Every AI coding request must follow this structure.

## 1. Context
What system or module is being changed?

## 2. Objective
What must be implemented or fixed?

## 3. Constraints
Technical, security, performance, or architectural limits.

## 4. Inputs / Outputs
Expected inputs and outputs.

## 5. Acceptance Criteria
Conditions required for the task to be considered done.

## 6. Edge Cases
Failure modes, unusual scenarios, or boundary conditions.

## 7. Test Requirements
Required unit, integration, or regression tests.
